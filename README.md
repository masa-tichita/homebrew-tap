# masa-tichita/homebrew-tap

Homebrew formulae by [masa-tichita](https://github.com/masa-tichita).

```sh
brew install masa-tichita/tap/roomy
```

| Formula | Description |
|---|---|
| [roomy](https://github.com/masa-tichita/roomy) | Keeps your Mac roomy: finds what is safe to delete, warns before storage or memory runs out. |

Formulae are updated automatically by each project's release workflow; please open issues and
pull requests in the project's own repository.
